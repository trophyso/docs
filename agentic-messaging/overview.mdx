Agentic messaging gives each of your users their own AI lifecycle marketing agent. Each agent reads that user's in-app activity, decides whether a message would help, picks the right channel and moment, and writes the message itself, all inside your brand guidelines.

There are no templates, journeys or sequences to build. You set the objectives and the rules, and agents do the work.

<Note>
  Agentic messaging is set up together with the Trophy team. [Book a
  call](https://trophy.so/contact-sales?utm_source=docs) to get started.
</Note>

## One agent per user, not one sequence for everyone {#one-agent-per-user}

Traditional customer engagement platforms move users through segments and sequences: branching workflows of triggers, delays and templates that every user flows through. Every user on the same path gets the same message at the same step.

Trophy treats each user as a cohort of one. Each agent works only for its user, so every message reflects that user's own experience in your app.

Take Mei, two weeks into a daily habit with a puzzle app. She's still playing every day, but her sessions are getting shorter and she's started playing late at night instead of on her commute.

- **A sequence-based platform** waits until Mei has been inactive for three days, then sends a generic "We miss you, Mei!".
- **A Trophy agent** spots the early signs while Mei's still active and gives her something new to work toward: "14 days in a row, Mei. You've been placed in your first weekly league with players at your level."

## How agents work {#how-agents-work}

Agents pick the best message for each user at the best moment. Sometimes the best message is no message, and agents only reach out when they have something worth saying.

## What agents learn from {#what-agents-learn-from}

Agents use the same data that powers the rest of Trophy:

- [Metrics](/data-sources/metrics) and [events](/data-sources/events) that describe how each user interacts with your app.
- [User attributes](/data-sources/users#custom-user-attributes) that you choose to share with agents in your [brand kit](/context/brand-kit).
- [Goals](/data-sources/goals) that each user is working towards, like deadlines, exams and study plans.
- In-app features like [streaks](/features/streaks), [milestones](/features/milestones) and [points](/features/points), which give agents first-party signals to write about.
- How each user engages with the messages they receive.

The more of your product you model in Trophy, the more context agents have to work with.

## Agentic and legacy messaging {#agentic-and-legacy-messaging}

Agentic messaging replaces template-based [emails](/features/emails) and [push notifications](/features/push-notifications) for the users it's rolled out to. Each user receives either agentic messages or legacy messages, never both.

Users in your [control group](/platform/experimentation#control-ratio) receive no messages from Trophy, which lets you [measure the impact](/agentic-messaging/measuring-impact) of agentic messaging against a clean baseline.
