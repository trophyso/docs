Una vez conectado, el servidor MCP de cuenta expone herramientas que tu agente puede llamar para inspeccionar y gestionar tu cuenta.

La mayoría de los recursos de configuración ofrecen herramientas **de lectura** y **escritura** emparejadas:

- Las herramientas **de lectura** listan y obtienen recursos
- Las herramientas **de escritura** crean o actualizan recursos por lotes para acelerar las operaciones

## Referencia de herramientas {#tool-reference}

La lista completa de herramientas disponibles en el servidor MCP de cuenta de Trophy.

### Herramientas de métricas {#metrics-tools}

Crea y gestiona las [Métricas](/es/features/metrics) que impulsan rachas, logros, puntos y clasificaciones.

| Herramienta | Qué hace |
| --- | --- |
| `read_metrics` | Lista métricas u obtiene una métrica individual por ID |
| `write_metrics` | Crea o actualiza métricas |

### Herramientas de atributos {#attributes-tools}

Gestiona [Atributos de usuario personalizados](/es/features/users#custom-user-attributes) y [Atributos de evento personalizados](/es/features/events#custom-event-attributes) utilizados para segmentación de funcionalidades y personalización.

| Herramienta | Qué hace |
| --- | --- |
| `read_attributes` | Lista atributos u obtiene un atributo individual por ID |
| `write_attributes` | Crea o actualiza atributos |

### Herramientas de logros {#achievements-tools}

Configura [Logros](/es/features/achievements) y lee analíticas de finalización para tu cuenta.

| Herramienta | Qué hace |
| --- | --- |
| `read_achievements` | Lista logros u obtiene un logro individual por ID |
| `write_achievements` | Crea o actualiza logros |
| `read_achievements_analytics` | Lista logros con conteos de finalización y rareza; opcionalmente filtra por `user_attributes` |

### Herramientas de clasificaciones {#leaderboards-tools}

Configura [Clasificaciones](/es/features/leaderboards) y lee clasificaciones en vivo.

| Herramienta | Qué hace |
| --- | --- |
| `read_leaderboards` | Listar clasificaciones o obtener una clasificación individual por ID |
| `write_leaderboards` | Crear o actualizar clasificaciones |
| `read_leaderboard_rankings` | Obtener una clasificación con rankings en vivo por clave (paginación opcional, fecha de ejecución, centrado en usuario y filtros de atributos) |

### Herramientas de Puntos {#points-tools}

Configure sistemas completos de [Puntos](/es/features/points), incluyendo [Triggers](/es/features/points#points-triggers), [Niveles](/es/features/points#points-levels) y [Boosts](/es/features/points#points-boosts), y consulte análisis de distribución.

| Herramienta | Qué hace |
| --- | --- |
| `read_points_systems` | Listar sistemas de puntos u obtener uno por ID |
| `write_points_systems` | Crear o actualizar sistemas de puntos (opcionalmente con triggers, niveles y boosts anidados) |
| `read_points_triggers` | Listar u obtener triggers para un sistema de puntos |
| `write_points_triggers` | Crear o actualizar triggers para un sistema de puntos |
| `read_points_levels` | Listar u obtener niveles para un sistema de puntos |
| `write_points_levels` | Crear o actualizar niveles para un sistema de puntos |
| `read_points_boosts` | Listar u obtener boosts para un sistema de puntos |
| `write_points_boosts` | Crear o actualizar boosts para un sistema de puntos |
| `read_points_analytics` | Distribución de puntos y desglose de niveles para un sistema (`summary` o `level_summary`; `user_attributes` opcional en el resumen) |

### Herramientas de Clientes {#tenants-tools}

Administre registros de organización [Multi-Tenant](/es/platform/multi-tenancy) cuando multi-tenancy esté habilitado en su cuenta.

| Herramienta | Qué hace |
| --- | --- |
| `read_tenants` | Listar clientes u obtener un cliente individual por ID |
| `write_tenants` | Crear o actualizar clientes |

<Note>
Si multi-tenancy no está habilitado en su cuenta, estas herramientas no funcionarán.
</Note>

### Herramientas de Rachas {#streaks-tools}

Consulta y ejecuta acciones operacionales de [Rachas](/es/features/streaks) para usuarios, incluyendo otorgar [Congelaciones de Racha](/es/features/streaks#streak-freezes), crear [Pausas de Racha](/es/features/streaks#streak-pauses), [restaurar rachas](/es/features/streaks#restoring-a-users-streak), y leer o actualizar la configuración de rachas de la organización.

| Herramienta | Qué hace |
| --- | --- |
| `list_user_streaks` | Obtener la longitud de racha (y última marca de tiempo de extensión) para hasta 100 usuarios, clasificados por la más larga primero |
| `grant_streak_freezes` | Otorgar congelaciones de racha a uno o más usuarios |
| `restore_streaks` | Restaurar una racha rota a su longitud anterior |
| `create_streak_pauses` | Crear pausas de racha para usuarios durante un rango de fechas (hasta 100 por solicitud) |
| `delete_streak_pauses` | Eliminar pausas de racha por ID (hasta 100 por solicitud) |
| `get_streak_settings` | Obtener la configuración de rachas de la organización (frecuencia, modo de evaluación, métricas, días libres, congelaciones) |
| `update_streak_settings` | Actualizar la configuración de rachas de la organización |

### Herramientas de Configuración {#settings-tools}

Lee y actualiza la configuración de la organización, incluyendo [Branding](/es/account/branding), [Experimentación](/es/platform/experimentation) y período de agregación.

| Herramienta | Qué hace |
| --- | --- |
| `get_settings` | Obtener la configuración de branding, experimentación y período de agregación |
| `update_settings` | Actualizar la configuración de branding, experimentación y período de agregación |

## Ejemplos de Prompts {#example-prompts}

Usa lenguaje natural — tu agente selecciona la herramienta y los parámetros correctos:

```text
Crea un sistema de XP llamado 'Kudos' que otorga 10 puntos por cada entrenamiento completado.
```

```text
Programa potenciadores de XP 2X para el sistema 'Kudos' durante los próximos 3 fines de semana (solo para usuarios de pago - el atributo 'plan' es 'pro').
```

```text
Lista todos los logros, tasas de finalización y rareza en mi cuenta de Trophy.
```

```text
Obtén el top 20 de rankings de la clasificación weekly-workouts de esta semana.
```

```text
Resume la distribución de puntos de Kudos para usuarios pro.
```

```text
¿Cuáles son las longitudes de racha actuales de los usuarios user_123 y user_456?
```

```text
Otorga dos congelaciones de racha al usuario user_123.
```

```text
user_123 quiere recuperar su racha, restáurala a su longitud anterior.
```

```text
Crea una pausa de racha para user_123 desde 2026-09-15 hasta 2026-09-22 mientras está de vacaciones.
```

```text
¿Cuál es nuestra configuración actual de rachas, y configura las congelaciones para empezar con 1 y un máximo de 3?
```

```text
Crea un logro llamado 'Primer Entrenamiento' que se desbloquea cuando los usuarios completan 1 entrenamiento.
```

```text
Actualiza nuestro color de marca a #0F766E y configura el período de agregación en semanal.
```

## Alcance y Seguridad {#scope-and-safety}

- Las herramientas solo actuarán en el [entorno](/es/platform/environments) de Trophy vinculado a la clave de API que pases en `x-trophy-api-key`.
- Las herramientas de escritura pueden cambiar la configuración en producción. Prefiere un [entorno](/es/platform/environments) de staging o sandbox al iterar.
- La mayoría de las herramientas no pueden eliminar recursos. La excepción es `delete_streak_pauses`, que elimina pausas de racha por ID.
