El Account MCP Server es un servidor remoto de [Model Context Protocol](https://modelcontextprotocol.io) que permite a los agentes de IA leer y gestionar la configuración de gamificación en tu cuenta de Trophy.

En lugar de copiar y pegar en el chat los clics del panel de control, puedes pedirle a tu agente que inspeccione métricas, cree sistemas de puntos, actualice clasificaciones, restaure rachas y mucho más.

```bash Server URL
https://mcp.trophy.so/mcp
```

## ¿Por qué el Account MCP? {#why-the-account-mcp}

Los agentes de programación con IA ya son parte del lugar donde los equipos diseñan y lanzan productos, y Trophy ha simplificado este proceso al ofrecer infraestructura prediseñada para crear funcionalidades de gamificación comunes. Sin embargo, esto implica en gran medida mirar pantallas y hacer clic en botones.

El Account MCP Server es la **capa de acción**: después de que el agente entiende *qué* debe crear (a menudo a través del [Docs MCP Server](/es/mcp/docs-mcp-server/introduction)), puede descubrir la configuración activa de la cuenta, aplicar cambios específicos y validar los resultados sin que una persona tenga que tocar el panel de control.

Esto abre un nuevo flujo de trabajo para los equipos: los agentes pueden razonar sobre qué funcionalidades de gamificación crear, entender cómo asignarlas a las funcionalidades de Trophy y configurar una cuenta de Trophy que lo logre todo desde el chat.

Flujos de trabajo habituales:

- Crear la estructura base de métricas, atributos y sistemas de puntos al integrar Trophy en una nueva aplicación
- Inspeccionar las clasificaciones o la configuración de puntos existentes antes de modificar el código de producción
- Ejecutar tareas operativas, como conceder congelaciones o restaurar rachas, desde el chat

## Cómo funciona {#how-it-works}

Trophy aloja un endpoint MCP remoto. Lo instalas una sola vez en tu cliente MCP, inicias sesión con OAuth usando tu cuenta de Trophy (y seleccionas la organización que quieres autorizar), y el cliente expone las herramientas que tu agente puede invocar.

Esas herramientas se corresponden con operaciones de la cuenta: list/get para el descubrimiento, create/update para la configuración y acciones específicas para congelaciones de racha, pausas, restauraciones, reinicios, ajustes y lectura de analíticas.

<Note>
  El servidor MCP de la cuenta está pensado para flujos de trabajo basados en chat y en agentes. Para scripts, tareas de backend o integraciones en producción, usa la [Admin API](/es/admin-api/introduction).
</Note>
