El servidor MCP de cuenta es un servidor remoto de [Model Context Protocol](https://modelcontextprotocol.io) que permite a los agentes de IA leer y gestionar la configuración de gamificación en tu cuenta de Trophy.

En lugar de copiar y pegar clics del panel de control en el chat, puedes pedirle a tu agente que inspeccione métricas, cree sistemas de puntos, actualice clasificaciones, restaure rachas y más.

```bash Server URL
https://mcp.trophy.so/mcp
```

## ¿Por qué el MCP de cuenta? {#why-the-account-mcp}

Los agentes de codificación de IA ya son donde los equipos diseñan y envían trabajo de producto, y Trophy ha simplificado esto al proporcionar infraestructura prediseñada para construir características comunes de gamificación. Sin embargo, esto implica en gran medida mirar pantallas y hacer clic en botones.

El servidor MCP de cuenta es la **capa de acción**: después de que el agente comprende *qué* construir (a menudo a través del [servidor MCP de documentación](/es/mcp/docs-mcp-server/introduction)), puede descubrir la configuración activa de la cuenta, realizar cambios específicos y validar resultados sin que un humano toque el panel de control.

Esto abre un nuevo flujo de trabajo para los equipos donde los agentes pueden razonar sobre qué características de gamificación construir, comprender cómo mapear eso a las características de Trophy y configurar una cuenta de Trophy que logre todo esto dentro del chat.

Los flujos de trabajo típicos incluyen:

- Estructurar métricas, atributos y sistemas de puntos al integrar Trophy en una nueva aplicación
- Inspeccionar clasificaciones existentes o configuración de puntos antes de cambiar el código de producción
- Ejecutar tareas operativas como otorgar congelaciones o restaurar rachas desde el chat

## Cómo funciona {#how-it-works}

Trophy aloja un endpoint MCP remoto. Lo instalas una vez en tu cliente MCP, inicias sesión con OAuth usando tu cuenta de Trophy (y seleccionas la organización a autorizar), y el cliente expone herramientas que tu agente puede llamar.

Estas herramientas se corresponden con operaciones de cuenta: list/get para descubrimiento, create/update para configuración, y acciones dedicadas para congelaciones de rachas, pausas, restauraciones, ajustes y lectura de analíticas.

<Note>
  El servidor MCP de cuenta está diseñado para flujos de trabajo basados en chat y agentes. Para scripts, trabajos backend o integraciones de producción, utiliza la [Admin API](/es/admin-api/introduction).
</Note>
