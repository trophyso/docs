<Note>
  Necesitas una [cuenta de Trophy](https://app.trophy.so/sign-up) para usar el servidor MCP de cuenta de Trophy.
</Note>

El servidor MCP de cuenta de Trophy es un servidor MCP HTTP remoto. Apunta tu cliente a la URL que aparece a continuación, completa el inicio de sesión OAuth con tu cuenta de Trophy cuando se te solicite, y tu agente podrá comenzar a usar las herramientas.

```bash Server URL
https://mcp.trophy.so/mcp
```

No se requieren claves de API. La autenticación utiliza OAuth: tu cliente MCP abre un navegador para que puedas iniciar sesión en Trophy y autorizar el acceso para la organización que selecciones.

## Instalar en tu cliente {#install-in-your-client}

Nombra este servidor claramente (por ejemplo `Trophy Account`) para que no entre en conflicto con el [servidor MCP de documentación](/es/mcp/docs-mcp-server/installation).

<Tabs>
  <Tab title="Claude">
    1. Abre [Conectores de Claude](https://claude.ai/new#settings/customize-connectors).
    2. Selecciona **Agregar > Agregar conector personalizado**.
    3. Agrega:
       - Nombre: `Trophy Account`
       - URL: `https://mcp.trophy.so/mcp`
    4. Completa el inicio de sesión OAuth cuando se te solicite y selecciona tu organización de Trophy.
    5. En el chat, usa el botón más para habilitar el conector de cuenta de Trophy o escribe 'Usando el servidor MCP de cuenta de Trophy...'.
  </Tab>
  <Tab title="Claude Code">
    Agrega el servidor remoto:

    ```bash
    claude mcp add --transport http "Trophy Account" https://mcp.trophy.so/mcp
    ```

    En el primer uso, Claude Code abre una ventana del navegador para completar el inicio de sesión OAuth. Inicia sesión en Trophy, selecciona tu organización y autoriza el acceso.

    Verifica que aparezca en tu lista:

    ```bash
    claude mcp list
    ```

  </Tab>
  <Tab title="Cursor">
    Abre la configuración de MCP y agrega esto a tu `mcp.json`:

    ```json
    {
      "mcpServers": {
        "Trophy Account": {
          "url": "https://mcp.trophy.so/mcp"
        }
      }
    }
    ```

    Recarga Cursor si es necesario, luego completa el inicio de sesión OAuth cuando se te solicite.
  </Tab>
  <Tab title="ChatGPT">
    Las aplicaciones MCP personalizadas requieren un plan de pago de ChatGPT con el [modo de desarrollador](https://platform.openai.com/docs/guides/developer-mode) habilitado.

    1. En ChatGPT, abre **Configuración → Seguridad e inicio de sesión** y activa el **Modo de desarrollador**.
    2. En un chat, abre el menú de suma y crea una aplicación en modo de desarrollador para tu servidor MCP remoto.
    3. Añade:
       - Nombre: `Trophy Account`
       - URL: `https://mcp.trophy.so/mcp`
       - Autenticación: **OAuth**
    4. Completa el inicio de sesión OAuth cuando se te solicite. Inicia sesión en Trophy y selecciona tu organización.
    5. En el chat, elige **Modo de desarrollador** desde el menú de suma y selecciona la aplicación Trophy Account para que ChatGPT pueda llamar a sus herramientas.
  </Tab>
  <Tab title="VS Code">
    Crea o actualiza `.vscode/mcp.json` en tu espacio de trabajo:

    ```json
    {
      "servers": {
        "Trophy Account": {
          "type": "http",
          "url": "https://mcp.trophy.so/mcp"
        }
      }
    }
    ```

    Recarga VS Code, habilita el servidor y completa el inicio de sesión OAuth cuando se te solicite.
  </Tab>
  <Tab title="Otros clientes">
    Cualquier cliente MCP que soporte servidores HTTP remotos y OAuth puede conectarse.

    Usa:

    - **Transporte:** HTTP (HTTP transmisible)
    - **URL:** `https://mcp.trophy.so/mcp`
    - **Nombre:** `Trophy Account` (o cualquier etiqueta que prefieras)
    - **Autenticación:** OAuth (inicio de sesión en el navegador a tu cuenta de Trophy; sin `headers` ni clave API)

    Después de añadir el servidor, completa el flujo OAuth y habilita el servidor en la interfaz del cliente si es necesario.
  </Tab>
</Tabs>

## Verifica la conexión {#verify-the-connection}

Pregunta a tu agente algo que requiera una llamada de cuenta en vivo, por ejemplo:

```text
List the metrics in my Trophy account.
```

Si la autenticación fue exitosa, deberías obtener métricas de tu organización. Si recibes un error de autenticación o no autorizado, reconecta el servidor y completa el inicio de sesión OAuth nuevamente, asegurándote de seleccionar la organización correcta de Trophy.
