El Servidor MCP de Documentación de Trophy y el Servidor MCP de Cuenta están diseñados para usarse juntos. Esta página cubre las formas recomendadas de utilizarlos.

## Usar Ambos Servidores Juntos {#using-both-servers-together}

Instala ambos servidores en tu cliente MCP usando nombres distintos para que las herramientas sean fáciles de identificar:

| Nombre recomendado | URL |
| --- | --- |
| `Trophy Docs` | `https://docs.trophy.so/mcp` |
| `Trophy Account` | `https://mcp.trophy.so/mcp` |

Guías de instalación: [MCP de Documentación](/es/mcp/docs-mcp-server/installation), [MCP de Cuenta](/es/mcp/account-mcp-server/installation).

## MCP de Documentación: Documentación en Vivo {#docs-mcp-live-documentation}

Usa el MCP de Documentación como contexto en vivo sobre cómo funciona Trophy. Úsalo cuando necesites:

- Entender el comportamiento de las funcionalidades de Trophy en detalle
- Pensar cómo resolver tu caso de uso específico de gamificación
- Encontrar la API correcta para llamar

El Servidor MCP de Documentación de Trophy es de **solo lectura** y siempre lee documentación pública en vivo, úsalo en lugar de copias locales para asegurar que tienes la información más actualizada.

Consulta las [capacidades del MCP de Documentación](/es/mcp/docs-mcp-server/capabilities) para más detalles.

## MCP de Cuenta: Configuración y Operaciones de Cuenta {#account-mcp-account-configuration-and-operations}

Usa el MCP de Cuenta cuando necesites realizar acciones en tu cuenta de Trophy. Úsalo cuando necesites:

- Leer configuración de tu cuenta de Trophy, por ejemplo, métricas, clasificaciones, etc.
- Configurar recursos nuevos o actualizar existentes en tu cuenta de Trophy mediante chat.
- Completar tareas operativas como otorgar congelaciones o restaurar rachas.

El acceso está limitado a la organización de Trophy que autorices durante OAuth. Las herramientas actúan en un [entorno](/es/platform/environments) específico (por defecto `production` o pasa otra clave cuando tengas múltiples).

Consulta [Capacidades del servidor MCP de cuenta](/es/mcp/account-mcp-server/capabilities) para más detalles.

## Flujo de trabajo recomendado {#recommended-workflow}

Para la mayoría del trabajo agéntico con Trophy, utiliza ambos servidores juntos:

1. **MCP de documentación** — carga la funcionalidad o el comportamiento de API que necesita la tarea
2. **MCP de cuenta (lectura)** — lista los recursos relacionados para que el trabajo se base en lo que ya existe
3. **MCP de cuenta (escritura)** — crea o actualiza solo lo que requiere la tarea
4. **Tu aplicación** — implementa las llamadas a la API de aplicación en código usando las estructuras respaldadas por la documentación y tus claves de API
5. **Verificar** — vuelve a leer el estado de la cuenta o la documentación si algo falla

### Ejemplo de prompt {#example-prompt}

```text
Using Trophy Docs MCP, review how metrics and event tracking works.
Using Trophy Account MCP, list my existing metrics.
Create a new 'workouts completed' metric if one does not already exist.
Then integrate event tracking to this metric in my code based on the docs.
```
