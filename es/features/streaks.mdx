## ¿Qué son las Rachas? {#what-are-streaks}

Una racha es un período de días, semanas o meses consecutivos en el que un usuario ha realizado una acción clave en tu plataforma. Se ha demostrado que las rachas aumentan significativamente la retención, especialmente cuando la acción del usuario que se rastrea se alinea con el valor central de tu producto.

## Frecuencia de Racha {#streak-frequency}

Las rachas en Trophy pueden ser **diarias, semanales o mensuales**. Esto significa que un usuario debe cumplir sus [condiciones de racha](#streak-conditions) al menos una vez cada día, semana o mes calendario para mantener su racha.

Si has [configurado zonas horarias](/es/features/users#param-tz) para tus usuarios, Trophy rastreará automáticamente la racha de cada usuario en su zona horaria local (incluyendo cuando los usuarios cambian de zona horaria) y mantendrá las rachas intactas.

<Note>
Trophy calcula automáticamente los datos de racha para cada frecuencia de racha, lo que significa que puedes cambiar en cualquier momento.
</Note>

## Condiciones de Racha {#streak-conditions}

En Trophy puedes establecer los umbrales que un usuario debe cumplir para extender su racha basándote en tus [Métricas](/es/features/metrics) configuradas.

Puedes elegir qué métricas deben ser parte de tu racha y, para las que elijas, puedes establecer un umbral personalizado que los usuarios deben cumplir.

Al combinar métricas, puedes elegir entre dos modos de evaluación:
- `ALL` significa que un usuario debe cumplir cada umbral de métrica para extender su racha
- `OR` significa que un usuario solo tiene que cumplir uno de tus umbrales de métrica para extender su racha

De esta manera puedes diseñar tu lógica de racha para que coincida con el caso de uso de tu aplicación.

### Días Libres {#days-off}

Para rachas diarias, puedes marcar días específicos de la semana como días libres en la [página de rachas](https://app.trophy.so/streaks) del panel de Trophy. Esos días no cuentan para la racha: los usuarios aún pueden extender su racha si están activos, pero perder un día libre no la romperá.

<Frame>
  <img
    height="200"

    noZoom

Debes dejar al menos un día que cuente para la racha. Las rachas semanales y mensuales ignoran los días libres.

A diferencia de las [congelaciones de racha](#streak-freezes), los días libres no se consumen. Se aplican cada semana hasta que los cambies.

Si has habilitado la [personalización de racha](#streak-personalization), los usuarios pueden anular los días libres predeterminados mediante las [preferencias de usuario](/es/features/users#streak-preferences).

## Congelaciones de Racha {#streak-freezes}

Las congelaciones de racha ayudan a los usuarios a mantener sus rachas por más tiempo al permitirles perder un número determinado de períodos sin que se restablezca a cero. Esto ayuda a mantener las rachas motivadoras incluso si los usuarios no mantienen un hábito de uso perfecto.

Las congelaciones de racha son opcionales y se pueden configurar en la [página de rachas](https://app.trophy.so/streaks) del panel de Trophy.

Cuando están habilitadas, decides cuántas congelaciones puede tener un usuario y cuántas se le otorgan con el tiempo. Cuando un usuario pierde un período, se consume una congelación. Las congelaciones se consumen hasta que los usuarios no tienen congelaciones restantes, momento en el cual la racha del usuario se restablece a cero.

<Note>
Las congelaciones de racha son diferentes de las [pausas de racha](#streak-pauses) en que las congelaciones permiten a los usuarios perder un número determinado de períodos sin romper su racha, independientemente del motivo, mientras que las pausas de racha protegen específicamente una racha durante un rango de fechas conocido y predefinido, como unas vacaciones o descanso programado. Las congelaciones se consumen automáticamente cuando el usuario pierde una actividad requerida, mientras que las pausas se crean manualmente con anticipación para cubrir ausencias planificadas.
</Note>

### Concesión de congelamientos {#granting-freezes}

Puede configurar cualquier número de congelamientos arbitrarios para otorgar a los nuevos usuarios cuando los identifique por primera vez con Trophy. Para configurar esto, habilite las concesiones de congelamiento y establezca el recuento inicial de congelamientos en la página de rachas del panel de Trophy.

## Pausas de racha {#streak-pauses}

Las pausas de racha protegen la racha de un usuario durante un rango de fechas conocido, como unas vacaciones u otro descanso planificado. Mientras una pausa cubre un período, Trophy mantiene la duración de la racha del usuario en lugar de finalizar la racha si no cumple con sus [condiciones de racha](#streak-conditions).

<Note>
Las pausas de racha son diferentes de los [congelamientos de racha](#streak-freezes) en que las pausas protegen específicamente la racha de un usuario durante un rango de fechas conocido y predefinido, como unas vacaciones programadas o un descanso, mientras que los congelamientos permiten a los usuarios perder un número establecido de días (o períodos) sin romper su racha, independientemente del motivo. Las pausas se crean manualmente con anticipación para cubrir ausencias planificadas, mientras que los congelamientos se consumen automáticamente cuando el usuario pierde una actividad requerida.
</Note>

### Crear pausas {#creating-pauses}

Crea pausas con la [API de administración para crear pausas de rachas](/es/admin-api/endpoints/streaks/create-pauses). Puedes crear pausas para hasta 100 usuarios en una única solicitud.

Cada pausa requiere:

- `userId`: el usuario para el que crear una pausa
- `start`: la primera fecha que cubre la pausa
- `end`: la última fecha que cubre la pausa

Las fechas de inicio en el pasado son rechazadas. Si has [configurado zonas horarias](/es/features/users#param-tz) para tus usuarios, Trophy evalúa `start` contra el día de hoy en la zona horaria local de cada usuario.

### Eliminar pausas {#deleting-pauses}

Para evitar que una pausa se aplique, elimínala con la [API de administración para eliminar pausas de rachas](/es/admin-api/endpoints/streaks/delete-pauses).

### Leer pausas {#reading-pauses}

La [API de rachas de usuario](/es/api-reference/endpoints/users/get-a-users-streak) devuelve las pausas próximas y actualmente activas en el campo `pauses`. Las pausas pasadas y eliminadas se omiten.

Cada período en `streakHistory` incluye `usedPause`, que es `true` cuando la racha del usuario estuvo en pausa durante ese período.

## Seguimiento de rachas {#tracking-streaks}

Trophy calcula automáticamente las rachas para todos los usuarios según los [eventos de métricas](/es/features/events#tracking-metric-events) que reportes a Trophy.

No se requiere trabajo adicional para hacer seguimiento de las rachas, y puedes comenzar a usarlas de inmediato. Solo asegúrate de que las rachas estén habilitadas en el panel de Trophy.

También puedes leer y actualizar la configuración de rachas de la organización — frecuencia, modo de evaluación, métricas, días libres, personalización y congelamientos — con la [API de administración de configuración de rachas](/es/admin-api/endpoints/streaks/update-streak-settings).

<Tip>
Para un recorrido completo sobre cómo configurar una funcionalidad de rachas usando Trophy, consulta nuestra [guía oficial](/es/guides/how-to-build-a-streaks-feature).
</Tip>

## Personalización de rachas {#streak-personalization}

Trophy puede permitir que los usuarios personalicen cómo funciona su racha dentro de los límites que establezcas para ellos. Para hacer esto, activa la personalización de rachas en la [página de rachas](https://app.trophy.so/streaks) del panel de Trophy.

Una vez habilitado, los usuarios podrán personalizar las [condiciones de racha](#streak-conditions) que deben cumplir para extender su racha, incluyendo el modo de evaluación de racha, el umbral para cada métrica y [días libres](#days-off), a través de las preferencias de usuario.

<Tip>
Para obtener más información sobre cómo establecer las preferencias de usuario para un usuario específico, consulta la documentación dedicada sobre [preferencias de usuario](/es/features/users#streak-preferences).
</Tip>

## Gestión de Rachas {#managing-streaks}

Esta sección describe algunas de las operaciones que puedes realizar para gestionar las rachas de los usuarios en tu aplicación.

### Restaurar la Racha de un Usuario {#restoring-a-users-streak}

Para restaurar la racha de un usuario, dirígete a la página de detalles del usuario y utiliza la acción 'Restaurar Racha'. Restaurar la racha de un usuario la establece a la longitud que tenía cuando la perdió por última vez.

<Tip>
También puedes usar la [API de administración para restaurar rachas](/es/admin-api/endpoints/streaks/restore-streaks) para restaurar rachas de forma programática.
</Tip>

## Mostrar Rachas {#displaying-streaks}

Trophy expone los datos de rachas de dos formas, que pueden utilizarse para construir elementos de interfaz dentro de tus aplicaciones y mostrar las rachas a los usuarios.

<Tip>
  Consulta nuestra [guía completa](/es/guides/how-to-build-a-streaks-feature) sobre cómo agregar una
  funcionalidad de rachas a tu aplicación para obtener más detalles.
</Tip>

### Respuesta de Evento de Métrica {#metric-event-response}

Cuando [incrementas una métrica](/es/features/events#tracking-metric-events) para un usuario, la respuesta de la [API de métricas](/es/api-reference/endpoints/events/submit-a-metric-event) incluirá la racha actual del usuario.

Esto puede utilizarse para activar de forma transaccional elementos de UI/UX incluyendo:

- Mostrar ventanas emergentes en la aplicación
- Reproducir efectos de sonido
