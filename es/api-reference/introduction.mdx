La API de la aplicación Trophy es un conjunto de endpoints que proporcionan interfaces simples para construir experiencias de gamificación y cubre toda la gama de acciones que un usuario final de su aplicación puede realizar.

No incluye funciones administrativas globales ni acciones que solo deben ser realizadas por sus sistemas internos. Si busca funcionalidad administrativa, consulte la [API de administración](/es/admin-api/introduction).

La API de la aplicación es accesible a través de [SDK](/es/api-reference/client-libraries) disponibles en la mayoría de los principales lenguajes de programación o, para aquellos que deseen gestionar sus propios clientes HTTP, está disponible en la siguiente URL base.

```bash Base URL
https://api.trophy.so/v1
```

<Tip>
La referencia completa de la API está disponible públicamente en [/openapi](https://api.trophy.so/v1/openapi).
</Tip>
