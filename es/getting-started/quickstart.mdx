Aquí integrarás tu aplicación con Trophy y comenzarás a construir tu primera funcionalidad gamificada.

<Tabs>
  <Tab title="Usando IA" icon="bot">
    Estas instrucciones son para quienes prefieren desarrollar usando agentes de código como Cursor y Claude Code.

    <Steps>
      <Step title="Crea tu cuenta de Trophy">
        Primero, [crea una nueva cuenta](https://app.trophy.so/sign-up?utm_source=docs&utm_medium=quickstart) si aún no tienes una y dirígete al [panel de Trophy](https://app.trophy.so).

        Completa el proceso de incorporación para configurar tu cuenta.
      </Step>

      <Step title="Configura los servidores MCP">
        Para obtener la mejor experiencia de configuración con IA, conecta Trophy a través de MCP:

        - URL del servidor MCP de documentación: `https://docs.trophy.so/mcp` (contexto de documentación en vivo)
        - URL del servidor MCP de cuenta: `https://mcp.trophy.so` (acciones de cuenta — consulta [MCP](/es/mcp/overview); requiere `x-trophy-api-key`)

        <Tip>
          Usa el [MCP de documentación](/es/mcp/docs-mcp-server/introduction) como contexto de documentación bajo demanda y el [MCP de cuenta](/es/mcp/account-mcp-server/introduction) para cambios en la cuenta. Usa ambos para seguir las [mejores prácticas](/es/mcp/best-practice).
        </Tip>

      </Step>
      <Step title="Indica a tu agente que realice la configuración inicial">
        Aquí tienes un prompt que puedes usar con tu agente de código para realizar la configuración inicial de Trophy:

        <Prompt
          description="Realizar la configuración inicial de Trophy"
          icon="paperclip"
          iconType="solid"
          actions={["copy", "cursor"]}
        >
          Estoy agregando gamificación a mi aplicación usando Trophy.

          Antes de realizar cambios, verifica que los servidores MCP de Trophy conectados estén disponibles. Usa el servidor MCP de documentación como la fuente principal de información para los detalles de integración de Trophy, y el servidor MCP de cuenta para configurar mi cuenta.

          Por favor, realiza la configuración inicial completa de principio a fin:
          1. Detecta el lenguaje/framework del backend en este repositorio e instala el SDK oficial de Trophy correspondiente (o usa llamadas HTTP si no hay un SDK disponible).
          2. Agrega `TROPHY_API_KEY` a la configuración de entorno de forma segura (sin secretos confirmados en git), e intégralo en la inicialización del cliente de Trophy.
          3. Agrega código para rastrear un evento de cambio de métrica para la métrica `<metric>` usando el cliente de la API de Trophy, conectando todos los atributos de usuario requeridos como el ID, y usando marcadores de posición para todos los atributos opcionales como nombre, correo electrónico, zona horaria y fecha de registro.
          4. Agrega manejo de errores básico y registro en torno a las llamadas a la API de Trophy.
          5. Agrega o actualiza una sección breve en el README que explique cómo funciona la integración y cómo extenderla.

          Restricciones:
          - Utiliza los resultados de la herramienta Docs MCP para todas las decisiones de implementación específicas de Trophy.
          - No te bases en la memoria previa para el comportamiento de la API de Trophy cuando MCP proporciona una respuesta.
          - Mantén los secretos fuera del control de código fuente.
          - Usa los patrones y convenciones de nomenclatura del proyecto existentes.
          - Muéstrame un resumen conciso de los archivos modificados y cómo probar la configuración.
          - Sugiere los siguientes pasos basándote en las funcionalidades de gamificación que Trophy admite.
        </Prompt>

        <Note>
          Asegúrate de reemplazar `<metric>` con la métrica que configuraste durante la incorporación.
        </Note>

        Esto hará lo siguiente:

        1. Agregará el [SDK de Trophy](/es/api-reference/client-libraries) relevante a tu aplicación según tu stack tecnológico
        2. Agregará una nueva variable `TROPHY_API_KEY` a tu configuración de entorno
        3. Agregará código para enviar eventos a Trophy basándose en la métrica que configuraste durante la incorporación.
      </Step>
      <Step title="Obtén tu clave de API">
        Una vez completada la configuración, [crea una clave de API](https://app.trophy.so/integration) desde la página de integración del panel de Trophy y agrégala a tu entorno.
      </Step>
      <Step title="Construye tu primera funcionalidad de gamificación">
        Una vez completada la configuración inicial, usa este prompt de seguimiento para preparar tu agente para el siguiente paso y haz que te pregunte qué construir a continuación:

        <Prompt
          description="Construye tu primera funcionalidad de gamificación"
          icon="paperclip"
          iconType="solid"
          actions={["copy", "cursor"]}
        >
          Prepárate para continuar mi integración de Trophy desde la configuración existente.

          Primero, verifica que el servidor Docs MCP de Trophy conectado esté disponible y úsalo como fuente confiable para los detalles de integración específicos de cada funcionalidad.

          Antes de implementar cualquier cosa, pregúntame qué funcionalidad de gamificación quiero construir, proporcionando opciones basadas en lo que el Docs MCP indica que Trophy admite.

          Después de que elija una opción:
          1. Configurar la funcionalidad seleccionada de la manera que describo usando el servidor MCP de Account.
          1. Implementar únicamente esa funcionalidad seleccionada usando las API de Trophy relevantes y los patrones existentes del proyecto.
          2. Agregar las llamadas/endpoints/acciones del lado del servidor necesarias que usan las API de Trophy y una interfaz de usuario mínima o superficie de respuesta de API.
          3. Documentar cualquier nueva variable de entorno, ruta y pasos de uso.

          Si solicito una funcionalidad que Trophy no admite, no implementes una solución alternativa.
          En su lugar, indícame que actualmente no está disponible y pídeme que me comunique con el soporte de Trophy en support@trophy.so para enviar una solicitud de funcionalidad.

          Mantén los cambios orientados a producción:
          - Sigue la arquitectura y las convenciones de nomenclatura existentes.
          - Maneja los fallos de API de forma elegante.
          - Devuelve una lista clara de archivos modificados y pasos de verificación manual.
        </Prompt>

    <Steps>
      <Step title="Crea tu cuenta de Trophy">

      <Step title="Agrega el SDK de Trophy a tu backend">
        Tenemos bibliotecas de SDK disponibles en la mayoría de los lenguajes de programación principales, pero si no ves el tuyo en la lista, ¡háznoslo saber y crearemos uno!

        <SdkInstallCommand />

        Alternativamente, puedes llamar directamente a la API usando cualquier cliente HTTP del lado del servidor.

      </Step>
      <Step title="Configura el entorno">
        Dirígete a la [página de integración](https://app.trophy.so/integration) del panel de Trophy y crea una nueva clave de API.
        
        Agrega tu clave de API como una variable de entorno en tu aplicación de backend:

        <AddEnvVarBlock />

        Luego inicializa el cliente de API de Trophy en tu backend usando esa clave de API:

        <TrophyClientInitBlock />

        Asegúrate de que todas las llamadas al SDK de Trophy usen este cliente para la autenticación.
      </Step>
      <Step title="Crea tu primera métrica">
        Todas las funciones de gamificación están impulsadas por interacciones de usuario. En Trophy, usas [Métricas](/es/features/metrics) para definir y modelar esas interacciones y [Eventos](/es/features/events) para rastrearlas.
        
        Aquí crearás tu primera métrica para comenzar. En el panel de Trophy, dirígete a la [página de métricas](https://app.trophy.so/metrics) y haz clic en el botón _Nueva Métrica_:

        <Frame>
          <video
            autoPlay
            muted
            loop
            playsInline
            className="w-full aspect-video"
            src="../../assets/features/metrics/create_new_metric.mp4"

        </Frame>

        Dale un nombre a la métrica y haz clic en _Guardar_.

      </Step>
      <Step title="Integra la métrica en tu backend">
        Una vez que hayas creado tu métrica, dirígete a la pestaña de configuración y copia su clave de referencia única de la API.

        <Frame>
          <video
            autoPlay
            muted
            loop
            playsInline
            className="w-full aspect-video"
            src="../../assets/quick-start/copy_metric_key.mp4"

        Para rastrear un evento contra esta métrica cuando un usuario interactúa con tu producto, llama a la [API de eventos de cambio de métrica](/es/api-reference/endpoints/events/submit-a-metric-event), pasando los detalles del usuario que realizó la interacción. En este ejemplo, la clave de la métrica sería `flashcards-flipped`:

        <MetricChangeRequestBlock />

        Al realizar esta llamada, le estás indicando a Trophy que un usuario específico realizó una interacción con tu producto. Como resultado, Trophy procesará automáticamente cualquier funcionalidad de gamificación como Logros o Rachas que hayas configurado contra la métrica.

      </Step>
