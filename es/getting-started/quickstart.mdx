Aquí integrarás tu aplicación con Trophy y comenzarás a construir tu primera función gamificada en aproximadamente cinco minutos.

<Tabs>
  <Tab title="Usando IA" icon="bot">
    Estas instrucciones son para usar Trophy con asistentes de IA que admiten MCP, por ejemplo Claude, ChatGPT, Cursor o Claude Code.

    <Steps>
      <Step title="Crea tu cuenta de Trophy">
        Primero, [crea una nueva cuenta](https://app.trophy.so/sign-up?utm_source=docs&utm_medium=quickstart) si aún no tienes una. Completa la incorporación para configurar tu cuenta.
      </Step>

      <Step title="Conecta los servidores MCP de Trophy">
        Conecta ambos servidores MCP de Trophy en tu cliente de IA para obtener la mejor experiencia:

        - URL del servidor MCP de documentación: `https://docs.trophy.so/mcp` (contexto de documentación en vivo)
        - URL del servidor MCP de cuenta: `https://mcp.trophy.so/mcp` (acciones de cuenta — inicio de sesión OAuth requerido)

        Guías de configuración: [Instalación del MCP de documentación](/es/mcp/docs-mcp-server/installation), [Instalación del MCP de cuenta](/es/mcp/account-mcp-server/installation).

        <Tip>
          Usa el [MCP de documentación](/es/mcp/docs-mcp-server/introduction) como contexto de documentación bajo demanda y el [MCP de cuenta](/es/mcp/account-mcp-server/introduction) para cambios de cuenta. Usa ambos para [mejores prácticas](/es/mcp/best-practice).
        </Tip>

      </Step>
      <Step title="Solicita a tu IA que realice la configuración inicial">
        Aquí hay un prompt que puedes usar con tu asistente de IA para realizar la configuración inicial de Trophy:

        <Prompt
          description="Realizar la configuración inicial de Trophy"
          icon="paperclip"
          iconType="solid"
          actions={["copy", "cursor"]}
        >
          Estoy agregando gamificación a mi aplicación usando Trophy.

          Antes de realizar cambios, verifica que los servidores MCP de Trophy conectados estén disponibles. Usa el servidor MCP de documentación como la fuente principal de verdad para los detalles de integración de Trophy, y el servidor MCP de cuenta para configurar mi cuenta.

          Por favor, realiza la configuración inicial completa de principio a fin:
          1. Detecta el lenguaje/framework del backend en este repositorio e instala el SDK oficial de Trophy correspondiente (o usa llamadas HTTP si no hay SDK disponible). Informa al soporte de Trophy si no hay SDK disponible.
          2. Agrega `TROPHY_API_KEY` a la configuración de entorno de forma segura (sin secretos confirmados en git), e intégralo en la inicialización del cliente del SDK de Trophy.
          3. Agrega código para configurar el seguimiento de eventos de métricas para la actividad de usuario elegida (pregunta si aún no se conoce) usando el cliente del SDK de Trophy, conectando todos los atributos de usuario requeridos como ID, y usando marcadores de posición para todos los atributos opcionales como nombre, email, tz y signUpDate, a menos que ya sean conocidos o requeridos por el caso de uso.
          4. Agrega manejo básico de errores y registro de eventos en torno a las llamadas del SDK de Trophy.
          5. Agrega o actualiza una sección breve del README explicando cómo funciona la integración y cómo extenderla.

          Restricciones:
          - Usa los resultados de la herramienta Docs MCP para todas las decisiones de implementación e integraciones específicas de Trophy.
          - No confíes en la memoria previa para el comportamiento del SDK de Trophy cuando MCP proporcione una respuesta.
          - Mantén los secretos fuera del control de código fuente.
          - Usa los patrones y convenciones de nomenclatura existentes del proyecto.
          - Muestra un resumen conciso de los archivos modificados y cómo probar la configuración.
          - Sugiere los siguientes pasos basados en las funciones de gamificación que Trophy soporta y el caso de uso.
        </Prompt>

        Esto hará lo siguiente:

        1. Agregará el [SDK de Trophy](/es/api-reference/client-libraries) correspondiente a tu aplicación según tu stack tecnológico
        2. Agregará una nueva variable `TROPHY_API_KEY` a tu configuración de entorno
        3. Agregará código para rastrear eventos de métricas para la actividad de usuario elegida usando el cliente del SDK de Trophy - requerido para todas las funciones de gamificación.
      </Step>
      <Step title="Construye tu primera función de gamificación">
        Una vez completada la configuración inicial, elige un caso de uso común y pega el prompt correspondiente en tu asistente de IA:

        <Prompt
          description="Racha diaria"
          icon="paperclip"
          iconType="solid"
          actions={["copy", "cursor"]}
        >
          Crea una funcionalidad de racha diaria con Trophy.

          Usa el MCP de Documentación como fuente de verdad para cómo funcionan las rachas, y el MCP de Cuenta para configurar mi cuenta.

          Objetivos:
          1. Impulsar la racha desde una actividad principal del usuario que ya se rastree (o que deberíamos rastrear) como una métrica de Trophy.
          2. Asegurar que cada identificación/actualización de usuario y evento de métrica incluya el atributo `tz` del usuario (zona horaria IANA). Esto es necesario para que las rachas evalúen correctamente los días calendario para cada usuario.
          3. Configurar la funcionalidad de racha en Trophy usando un umbral sensato para la métrica elegida.
          4. Habilitar congelaciones de racha y pausas de racha si encajan con este producto; de lo contrario, omitirlas y explicar por qué.
          5. Conectar cualquier lectura del lado de la aplicación o interfaz necesaria para mostrar la racha actual del usuario, congelaciones y estado de pausa.
          6. Resumir qué se configuró, qué código cambió y cómo verificar la racha de principio a fin. Explicar explícitamente por qué enviar `tz` es importante para que funcione correctamente la funcionalidad de racha.
        </Prompt>

        <Prompt
          description="Biblioteca de logros"
          icon="paperclip"
          iconType="solid"
          actions={["copy", "cursor"]}
        >
          Crea una biblioteca de logros con Trophy.

          Usa el MCP de Documentación como fuente de verdad para tipos de logros y activadores, y el MCP de Cuenta para configurar mi cuenta.

          Objetivos:
          1. Crear un conjunto de logros vinculados a acciones principales del usuario rastreadas como eventos de métrica de Trophy.
          2. Agregar cualquier logro activado por API de una sola vez (y otros tipos de logros) que encajen con el producto.
          3. Conectar el manejo del lado de la aplicación para desbloqueos y una forma mínima de listar logros completados vs incompletos.
          4. Resumir qué se configuró, qué código cambió y cómo verificar los desbloqueos de principio a fin.
        </Prompt>

        <Prompt
          description="Sistema XP"
          icon="paperclip"
          iconType="solid"
          actions={["copy", "cursor"]}
        >
          Crea un sistema de puntos XP con Trophy.

          Usa el MCP de Documentación como fuente de verdad para sistemas de puntos, activadores y niveles, y el MCP de Cuenta para configurar mi cuenta.

          Objetivos:
          1. Crear un sistema de puntos que otorgue XP por algunas acciones clave del usuario rastreadas como métricas de Trophy.
          2. Configurar activadores en el sistema de puntos para otorgar XP por las acciones de usuario elegidas.
          3. Configurar niveles y bonificaciones si son relevantes para el caso de uso.
          4. Implementar las lecturas del lado de la aplicación o la interfaz necesarias para mostrar el total de XP del usuario y el progreso de nivel.
          5. Resumir qué se configuró, qué código cambió y cómo verificar las asignaciones de puntos de extremo a extremo.
        </Prompt>

        <Prompt
          description="Clasificación semanal"
          icon="paperclip"
          iconType="solid"
          actions={["copy", "cursor"]}
        >
          Crea una clasificación semanal recurrente con Trophy.

          Usa el MCP de Documentación como fuente de verdad para clasificaciones, y el MCP de Cuenta para configurar mi cuenta.

          Objetivos:
          1. Crear una clasificación recurrente semanal impulsada por una acción central del usuario rastreada como una métrica de Trophy.
          2. Configurar la lógica de clasificación basada en la métrica elegida y configurar el calendario de reinicio semanal para la clasificación.
          3. Implementar las lecturas del lado de la aplicación o la interfaz necesarias para mostrar las clasificaciones de la semana actual y la posición del usuario actual.
          4. Resumir qué se configuró, qué código cambió y cómo verificar las clasificaciones de extremo a extremo.
        </Prompt>

  <Tab title="Manual" icon="user">
    Estas instrucciones son para quienes desean implementar Trophy manualmente. Si en cambio prefieres usar IA, cambia de pestaña arriba.
    
    <Steps>
      <Step title="Crea tu cuenta de Trophy">
        Primero, [crea una nueva cuenta](https://app.trophy.so/sign-up?utm_source=docs&utm_medium=quickstart) si aún no tienes una y dirígete al [panel de Trophy](https://app.trophy.so).

        Completa la configuración inicial para configurar tu cuenta.

      </Step>
      <Step title="Añade el SDK de Trophy a tu backend">
        Tenemos bibliotecas SDK disponibles en los principales lenguajes de programación, pero si no ves el tuyo en la lista, ¡avísanos y crearemos uno!

        <SdkInstallCommand />

        Alternativamente, puedes llamar directamente a la API usando cualquier cliente HTTP del lado del servidor.

      </Step>
      <Step title="Configura el entorno">
        Dirígete a la [página de integración](https://app.trophy.so/integration) del panel de Trophy y crea una nueva clave API.
        
        Añade tu clave API como variable de entorno en tu aplicación backend:

        <AddEnvVarBlock />

        Luego inicializa el cliente de la API de Trophy en tu backend usando esa clave API:

        <TrophyClientInitBlock />

        Asegúrate de que todas las llamadas del SDK de Trophy usen este cliente para la autenticación.
      </Step>
      <Step title="Crea tu primera métrica">
        Todas las funciones de gamificación se basan en las interacciones de los usuarios. En Trophy, usas [Métricas](/es/features/metrics) para definir y modelar esas interacciones y [Eventos](/es/features/events) para rastrearlos.
        
        Aquí crearás tu primera métrica para comenzar. En el panel de Trophy, dirígete a la [página de métricas](https://app.trophy.so/metrics) y haz clic en el botón _Nueva Métrica_:

        <Frame>
          <video
            autoPlay
            muted
            loop
            playsInline
            className="w-full aspect-video"
            src="../../assets/features/metrics/create_new_metric.mp4"
          ></video>
        </Frame>

        Dale un nombre a la métrica y haz clic en _Guardar_.

      </Step>
      <Step title="Integra la métrica en tu backend">
        Una vez que hayas creado tu métrica, ve a la pestaña de configuración y copia su clave de referencia API única.

        <Frame>
          <video
            autoPlay
            muted
            loop
            playsInline
            className="w-full aspect-video"
            src="../../assets/quick-start/copy_metric_key.mp4"
          ></video>
        </Frame>

        Para rastrear un evento contra esta métrica cuando un usuario interactúa con tu producto, llama a la [API de evento de cambio de métrica](/es/api-reference/endpoints/events/submit-a-metric-event), pasando los detalles del usuario que realizó la interacción. En este ejemplo, la clave de métrica sería `flashcards-flipped`:

        <VerifiedFirstEvent />

        Al realizar esta llamada, le estás indicando a Trophy que un usuario específico realizó una interacción con tu producto. Como resultado, Trophy procesará automáticamente cualquier función de gamificación como logros o rachas que hayas configurado para la métrica.
        
        Utiliza la respuesta para reaccionar a los cambios en el estado de gamificación del usuario y alimentar elementos de la interfaz:

        <MetricChangeResponseBlock />

      </Step>
