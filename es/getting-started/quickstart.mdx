Aquí integrarás tu aplicación con Trophy y comenzarás a construir tu primera función gamificada.

<Tabs>
  <Tab title="Usando IA" icon="bot">
    Estas instrucciones son para usar Trophy con asistentes de IA que soporten MCP — por ejemplo Claude, ChatGPT, Cursor o Claude Code.

    <Steps>
      <Step title="Crea tu cuenta de Trophy">
        Primero, [crea una cuenta nueva](https://app.trophy.so/sign-up?utm_source=docs&utm_medium=quickstart) si aún no tienes una. Completa la incorporación para configurar tu cuenta.
      </Step>

      <Step title="Conecta los servidores MCP de Trophy">
        Conecta ambos servidores MCP de Trophy en tu cliente de IA para obtener la mejor experiencia:

        - URL del servidor MCP de documentación: `https://docs.trophy.so/mcp` (contexto de documentación en vivo)
        - URL del servidor MCP de cuenta: `https://mcp.trophy.so/mcp` (acciones de cuenta — inicio de sesión OAuth requerido)

        Guías de configuración: [Instalación de MCP de documentación](/es/mcp/docs-mcp-server/installation), [Instalación de MCP de cuenta](/es/mcp/account-mcp-server/installation).

        <Tip>
          Usa el [MCP de documentación](/es/mcp/docs-mcp-server/introduction) como contexto de documentación bajo demanda y el [MCP de cuenta](/es/mcp/account-mcp-server/introduction) para cambios de cuenta. Usa ambos para [mejores prácticas](/es/mcp/best-practice).
        </Tip>

      </Step>
      <Step title="Pide a tu IA que realice la configuración inicial">
        Aquí tienes un prompt que puedes usar con tu asistente de IA para realizar la configuración inicial de Trophy:

        <Prompt
          description="Realizar la configuración inicial de Trophy"
          icon="paperclip"
          iconType="solid"
          actions={["copy", "cursor"]}
        >
          Estoy añadiendo gamificación a mi aplicación usando Trophy.

          Antes de hacer cambios, verifica que los servidores MCP de Trophy conectados estén disponibles. Usa el servidor MCP de documentación como la fuente principal de información para los detalles de integración de Trophy, y el servidor MCP de cuenta para configurar mi cuenta.

          Realiza la configuración inicial completa de principio a fin:
          1. Detecta el lenguaje/framework del backend en este repositorio e instala el SDK oficial de Trophy correspondiente (o utiliza llamadas HTTP si no hay SDK disponible). Informa al soporte de Trophy si no hay SDK disponible.
          2. Agrega `TROPHY_API_KEY` a la configuración de entorno de forma segura (sin secretos comprometidos en git), e intégralo en la inicialización del cliente del SDK de Trophy.
          3. Agrega código para configurar el seguimiento de eventos de métricas para la actividad de usuario elegida (pregunta si aún no se conoce) usando el cliente del SDK de Trophy, conectando todos los atributos de usuario requeridos como ID, y usando marcadores de posición para todos los atributos opcionales como nombre, email, zona horaria y fecha de registro, a menos que ya se conozcan o sean requeridos por el caso de uso.
          4. Agrega manejo básico de errores y registro de eventos alrededor de las llamadas al SDK de Trophy.
          5. Agrega o actualiza una breve sección en el README explicando cómo funciona la integración y cómo ampliarla.

          Restricciones:
          - Utiliza los resultados de la herramienta Docs MCP para todas las decisiones de implementación e integraciones específicas de Trophy.
          - No te bases en memoria previa para el comportamiento del SDK de Trophy cuando MCP proporcione una respuesta.
          - Mantén los secretos fuera del control de código fuente.
          - Usa los patrones y convenciones de nomenclatura del proyecto existentes.
          - Muestra un resumen conciso de los archivos modificados y cómo probar la configuración.
          - Sugiere los próximos pasos basándote en las funciones de gamificación que Trophy soporta y el caso de uso.
        </Prompt>

        Esto hará lo siguiente:

        1. Agregar el [SDK de Trophy](/es/api-reference/client-libraries) relevante a tu aplicación según tu stack tecnológico
        2. Agregar una nueva variable `TROPHY_API_KEY` a tu configuración de entorno
        3. Agregar código para rastrear eventos de métricas para la actividad de usuario elegida usando el cliente del SDK de Trophy - requerido para todas las funciones de gamificación.
      </Step>
      <Step title="Construye tu primera función de gamificación">
        Una vez completada la configuración inicial, elige un caso de uso común y pega el prompt correspondiente en tu asistente de IA:

        <Prompt
          description="Racha diaria"
          icon="paperclip"
          iconType="solid"
          actions={["copy", "cursor"]}
        >
          Crea una función de racha diaria con Trophy.

          Usa el MCP de Docs como fuente de referencia para cómo funcionan las rachas, y el MCP de Account para configurar mi cuenta.

          Objetivos:
          1. Impulsa la racha desde una actividad de usuario principal ya rastreada (o que debería rastrearse) como una métrica de Trophy.
          2. Asegúrate de que cada identificación/actualización de usuario y evento de métrica incluya el atributo `tz` del usuario (zona horaria IANA). Esto es necesario para que las rachas evalúen correctamente los días calendario para cada usuario.
          3. Configura la función de racha en Trophy usando un umbral sensato para la métrica elegida.
          4. Habilita los congelamientos de racha y las pausas de racha si se ajustan a este producto; de lo contrario, omítelos y explica por qué.
          5. Conecta cualquier lectura del lado de la aplicación o interfaz necesaria para mostrar la racha actual del usuario, los congelamientos y el estado de pausa.
          6. Resume qué se configuró, qué código cambió y cómo verificar la racha de extremo a extremo. Explica explícitamente por qué enviar `tz` es importante para que funcione correctamente la función de racha.
        </Prompt>

        <Prompt
          description="Biblioteca de logros"
          icon="paperclip"

          Objetivos:
          1. Crea un conjunto de logros vinculados a acciones de usuario principales rastreadas como eventos de métrica de Trophy.
          2. Agrega cualquier logro único activado por API (y otros tipos de logros) que se ajusten al producto.
          3. Conecta el manejo del lado de la aplicación para los desbloqueos y una forma mínima de listar logros completados vs incompletos.
          4. Resume qué se configuró, qué código cambió y cómo verificar los desbloqueos de extremo a extremo.
        </Prompt>

        <Prompt
          description="Sistema XP"
          icon="paperclip"

          Construye un sistema de Puntos XP con Trophy.

          Utiliza el MCP de Documentación como fuente de verdad para sistemas de Puntos, activadores y niveles, y el MCP de Cuenta para configurar mi cuenta.

          Objetivos:
          1. Crear un sistema de Puntos que otorgue XP por algunas acciones clave del usuario rastreadas como Métricas de Trophy.
          2. Configurar activadores en el sistema de Puntos para otorgar XP por las acciones de usuario elegidas.
          3. Configurar niveles e impulsos si son relevantes para el caso de uso.
          4. Conectar lecturas del lado de la aplicación o interfaz necesaria para mostrar el total de XP del usuario y el progreso de nivel.
          5. Resumir qué se configuró, qué código cambió y cómo verificar las asignaciones de Puntos de extremo a extremo.
        </Prompt>

        <Prompt
          description="Clasificación semanal"
          icon="paperclip"
          iconType="solid"

        >
          Construye una Clasificación semanal recurrente con Trophy.

          Utiliza el MCP de Documentación como fuente de verdad para Clasificaciones, y el MCP de Cuenta para configurar mi cuenta.

          Objetivos:
          1. Crear una Clasificación recurrente semanal impulsada por una acción principal del usuario rastreada como una Métrica de Trophy.
          2. Configurar la lógica de clasificación basada en la Métrica elegida y configurar el programa de reinicio semanal para la Clasificación.
          3. Conectar lecturas del lado de la aplicación o interfaz necesaria para mostrar clasificaciones de la semana actual y el lugar del usuario actual.
          4. Resumir qué se configuró, qué código cambió y cómo verificar las clasificaciones de extremo a extremo.

  <Tab title="Manual" icon="user">
    Estas instrucciones son para quienes desean implementar Trophy manualmente. Si prefieres usar IA, cambia de pestaña arriba.
    
    <Steps>
      <Step title="Crea tu cuenta de Trophy">
        Primero, [crea una nueva cuenta](https://app.trophy.so/sign-up?utm_source=docs&utm_medium=quickstart) si aún no tienes una y dirígete al [panel de Trophy](https://app.trophy.so).

        Completa la configuración inicial para preparar tu cuenta.

      </Step>
      <Step title="Añade el SDK de Trophy a tu backend">
        Tenemos bibliotecas del SDK disponibles en los principales lenguajes de programación, pero si no encuentras el tuyo en la lista, ¡avísanos y crearemos uno!

        <SdkInstallCommand />

        Alternativamente, puedes llamar directamente a la API usando cualquier cliente HTTP del lado del servidor.

      </Step>
      <Step title="Configura el entorno">
        Dirígete a la [página de integración](https://app.trophy.so/integration) del panel de Trophy y crea una nueva clave de API.
        
        Añade tu clave de API como variable de entorno en tu aplicación backend:

        <AddEnvVarBlock />

        Luego inicializa el cliente de la API de Trophy en tu backend usando esa clave de API:

        <TrophyClientInitBlock />

        Asegúrate de que todas las llamadas al SDK de Trophy utilicen este cliente para la autenticación.
      </Step>
      <Step title="Crea tu primera métrica">
        Todas las funciones de gamificación se basan en interacciones de usuarios. En Trophy, usas [Métricas](/es/features/metrics) para definir y modelar esas interacciones y [Eventos](/es/features/events) para rastrearlas.
        
        Aquí crearás tu primera métrica para comenzar. En el panel de Trophy, dirígete a la [página de métricas](https://app.trophy.so/metrics) y presiona el botón _Nueva Métrica_:

        <Frame>
          <video
            autoPlay
            muted
            loop
            playsInline
            className="w-full aspect-video"
            src="../../assets/features/metrics/create_new_metric.mp4"
          ></video>
        </Frame>

        Dale un nombre a la métrica y presiona _Guardar_.

      </Step>
      <Step title="Integra la métrica en tu backend">
        Una vez que hayas creado tu métrica, dirígete a la pestaña de configuración y copia su clave de referencia de API única.

        <Frame>
          <video
            autoPlay
            muted
            loop
            playsInline
            className="w-full aspect-video"
            src="../../assets/quick-start/copy_metric_key.mp4"
          ></video>
        </Frame>

        Para rastrear un evento asociado a esta métrica cuando un usuario interactúa con tu producto, llama a la [API de eventos de cambio de métrica](/es/api-reference/endpoints/events/submit-a-metric-event), pasando los detalles del usuario que realizó la interacción. En este ejemplo, la clave de métrica sería `flashcards-flipped`:

        <MetricChangeRequestBlock />

        Al realizar esta llamada, le estás indicando a Trophy que un usuario específico ha interactuado con tu producto. Como resultado, Trophy procesará automáticamente cualquier función de gamificación, como logros o rachas, que hayas configurado para la métrica.

      </Step>
