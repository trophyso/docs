Trophy is built around a set of key concepts that power both agentic messaging and in-app features, while still offering enough customization to fit any web or mobile app.

## Data sources {#platform-concepts}

Trophy's data sources are the scalable building blocks that power every Trophy feature, including agentic messaging. These are the main things for developers to get comfortable with.

  <Card title="Metrics" icon="box" href="/data-sources/metrics">

</CardGroup>

## In-app features {#gamification-concepts}

Trophy's in-app features are flexible primitives built on your data sources. They give users a reason to come back, and give lifecycle agents rich first-party data about each user's progress.
